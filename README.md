# TPI Investigación Operativa - Modelos de Red

Esta aplicación web interactiva fue desarrollada para diseñar y resolver problemas clásicos de redes y grafos de manera visual. La herramienta permite a los usuarios colocar nodos, establecer conexiones con sus respectivos valores y calcular:

* El camino más corto (algoritmo de Dijkstra).
* La conexión de red al menor costo o árbol de expansión mínima (algoritmos de Prim y Kruskal).
* El flujo máximo soportado por una red (algoritmo de Ford-Fulkerson).
